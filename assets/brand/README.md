# CRMini — assets de empacotamento

As cópias abaixo vêm do diretório `app/` do Brand Kit e ficam separadas dos assets servidos pela aplicação:

- `app/crmini-windows.ico` — ícone Windows.
- `app/crmini-macos.icns` — ícone macOS.
- `app/crmini-linux.png` — ícone Linux.

Estes arquivos foram apenas organizados para uso posterior. A integração Electron e o `package.json` não foram alterados nesta etapa.
